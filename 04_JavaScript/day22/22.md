=====================================================================
API CALL FLOW (JS + AXIOS + EVENT LISTENER)
=====================================================================

------------------------------------------------------------
1) URL (API ENDPOINT)
------------------------------------------------------------
• URL = address of server/API
• Example:
  let url = "https://api.example.com/data";

✔ Alone → does nothing
✔ Needs HTTP request (GET/POST) to fetch data


------------------------------------------------------------
2) SELECT ELEMENT (BUTTON)
------------------------------------------------------------
HTML:
<button id="btn">Fetch Data</button>

JS:
let btn = document.querySelector("#btn");

✔ querySelector → selects element from DOM
✔ Used to connect JS with HTML


------------------------------------------------------------
3) ADD EVENT LISTENER
------------------------------------------------------------
btn.addEventListener("click", callbackFunction);

Example:
btn.addEventListener("click", function () {
    // runs when user clicks
});

✔ Makes app interactive
✔ Code runs ONLY when event happens


------------------------------------------------------------
4) ASYNC FUNCTION + AXIOS (CORE LOGIC)
------------------------------------------------------------
btn.addEventListener("click", async function () {

    try {
        let res = await axios.get(url);   // API call (GET)

        console.log(res.data);            // response data

    } catch (err) {
        console.error(err);               // error handling
    }

});

✔ axios.get() → returns Promise
✔ await → waits for response
✔ res.data → actual data from API


------------------------------------------------------------
5) DISPLAY DATA IN DOM
------------------------------------------------------------

A) Simple text:
document.querySelector("#output").innerText = res.data;

B) Object:
document.querySelector("#output").innerText =
    JSON.stringify(res.data);

C) Specific field:
document.querySelector("#output").innerText =
    res.data.fact;

✔ innerText / innerHTML used to update UI


------------------------------------------------------------
6) IMAGE API EXAMPLE (IMPORTANT)
------------------------------------------------------------

btn.addEventListener("click", async () => {

    try {
        let res = await axios.get(url2);

        let img = document.querySelector("#dog-img");

        img.setAttribute("src", res.data.message);

        console.log(res.data.message);

    } catch (e) {
        console.log("Error fetching image:", e);
    }

});

✔ res.data.message → image URL
✔ setAttribute("src", URL) → updates image


------------------------------------------------------------
7) COMPLETE FLOW
------------------------------------------------------------
User clicks button
→ Event listener triggers
→ axios sends request to URL
→ Server processes request
→ Response received
→ res.data extracted
→ DOM updated (text/image)


------------------------------------------------------------
8) KEY CONCEPTS (QUICK RECALL)
------------------------------------------------------------
• URL → API address
• querySelector → select HTML element
• addEventListener → handle user action
• axios.get() → HTTP request (Promise)
• async/await → clean async handling
• try/catch → error handling
• res.data → actual API data
• DOM update → show result to user


------------------------------------------------------------
INTERVIEW LINE 🚀
------------------------------------------------------------
On button click, we use addEventListener to trigger an async
function, call an API using axios, and update the DOM with
the received data.
