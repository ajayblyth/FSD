=====================================================================
ASYNC JAVASCRIPT – IMPORTANT QUESTIONS (INTERVIEW NOTES)
=====================================================================

------------------------------------------------------------
1) EVENT LOOP FLOW (CALLSTACK / MICROTASK / MACROTASK)
------------------------------------------------------------
Execution Order Priority:
1. Call Stack (synchronous code)
2. Microtask Queue (Promises, .then, queueMicrotask)
3. Macrotask Queue (setTimeout, setInterval, I/O)

Flow:
------------------------------------------------------------
Call Stack → executes sync code first

Then Event Loop checks:
✔ Microtask Queue → executes ALL tasks
✔ Then Macrotask Queue → executes ONE task

Example:
------------------------------------------------------------
console.log("A");

setTimeout(() => console.log("B"), 0);   // Macrotask
Promise.resolve().then(() => console.log("C")); // Microtask

console.log("D");

Output:
A D C B

Reason:
- A, D → sync (call stack)
- C → microtask (higher priority)
- B → macrotask (last)

------------------------------------------------------------
KEY RULE:
Microtasks ALWAYS run before Macrotasks


=====================================================================
2) PROMISE WITHOUT .then()
=====================================================================
Example:
------------------------------------------------------------
let p = Promise.resolve("Done");

👉 Nothing will print

Reason:
- Promise executes
- But no consumer (.then / .catch)
- So result is ignored

✔ Promise runs, but output is unused


=====================================================================
3) WHAT IF WE DON'T USE .catch()
=====================================================================
Example:
------------------------------------------------------------
Promise.reject("Error occurred");

👉 Unhandled Promise Rejection

Behavior:
- Browser → shows warning
- Node.js → may crash (strict mode)

✔ Always use .catch()

------------------------------------------------------------
BEST PRACTICE:
promise
  .then(...)
  .catch(...)
  .finally(...)


=====================================================================
4) FINALLY vs TRY/CATCH (ASYNC-AWAIT)
=====================================================================
Example:
------------------------------------------------------------
async function test() {
  try {
    console.log("TRY");
    return "Success";
  } catch (e) {
    console.log("CATCH");
  } finally {
    console.log("FINALLY");
  }
}

test().then(console.log);

Output:
TRY
FINALLY
Success

------------------------------------------------------------
KEY POINTS:
✔ finally ALWAYS runs
✔ runs AFTER try/catch but BEFORE .then()
✔ does NOT change return value (unless explicitly returned)


=====================================================================
5) CALLBACK → PROMISE CONVERSION
=====================================================================
Callback:
------------------------------------------------------------
function cbFunc(cb) {
  setTimeout(() => cb("Done"), 1000);
}

Promise version:
------------------------------------------------------------
function cbFunc() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Done"), 1000);
  });
}


=====================================================================
6) API (WHAT IS IT?)
=====================================================================
API = Application Programming Interface

✔ Allows communication between frontend & backend
✔ Usually HTTP based (GET, POST, PUT, DELETE)

Example:
------------------------------------------------------------
fetch("/users") → get data from server


=====================================================================
7) FETCH vs AXIOS
=====================================================================

FETCH:
------------------------------------------------------------
✔ Built-in (no install)
✔ Returns Promise
❌ Does NOT reject on HTTP errors (404, 500)

AXIOS:
------------------------------------------------------------
✔ External library
✔ Automatically rejects on HTTP errors
✔ Cleaner syntax
✔ Supports request/response interceptors

Example:
------------------------------------------------------------
fetch:
fetch(url).then(res => res.json())

axios:
axios.get(url).then(res => res.data)


=====================================================================
8) DISADVANTAGES OF PROMISES
=====================================================================

1) Long chaining (still messy)
--------------------------------
.then().then().then()...

2) Error handling confusion
--------------------------------
Need proper .catch placement

3) Sequential execution (slow)
--------------------------------
await a → await b (runs one after another)

4) Harder debugging (stack traces)

------------------------------------------------------------
SOLUTION:
✔ Use async/await (cleaner)
✔ Use Promise.all() (parallel execution)


=====================================================================
9) MICROTASK vs MACROTASK
=====================================================================

MICROTASK:
------------------------------------------------------------
✔ Promise.then
✔ queueMicrotask
✔ MutationObserver

✔ Runs immediately after current code
✔ Higher priority

MACROTASK:
------------------------------------------------------------
✔ setTimeout
✔ setInterval
✔ setImmediate (Node)

✔ Runs after microtasks


=====================================================================
10) PROMISE WITHOUT CONSUMPTION (IMPORTANT)
=====================================================================
new Promise((resolve) => {
  console.log("Running");
  resolve("Done");
});

Output:
Running

👉 Executor runs immediately
👉 But result is unused without .then()

=====================================================================
FINAL QUICK SUMMARY
=====================================================================
✔ JS is single-threaded
✔ Sync code runs first
✔ Microtasks > Macrotasks
✔ Promise needs .then/.catch to use result
✔ .catch prevents unhandled rejection
✔ finally always runs
✔ async/await = cleaner promise handling
✔ Promise.all = parallel execution
