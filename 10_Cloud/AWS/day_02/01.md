EC2 (Elastic Compute Cloud): a server in minutes
========================================================================================================================

Definition
----------
EC2 = Virtual Server in AWS.
An EC2 Instance = One virtual server that is ready in minutes.

+----------------+---------------------------------------------------------+---------------------------+
| Instance Type  | Description                                             | Best For                  |
+----------------+---------------------------------------------------------+---------------------------+
| On-Demand      | Pay only while running. No long-term commitment.        | Learning (Used in course) |
| Reserved       | Commit for 1-3 years to get discounts.                  | Production                |
| Spot           | Cheapest spare capacity. Can be terminated anytime.     | Batch Jobs                |
+----------------+---------------------------------------------------------+---------------------------+

Rule of Thumb
-------------
On-Demand = Flexible
Reserved  = Save Money (Long-term)
Spot       = Cheapest but can disappear anytime

Note:
Security Groups (Networking)
Security Groups act as a virtual firewall for an EC2 instance.

Inbound Rules
-------------
Control incoming traffic to the instance.
Example:
• SSH (Port 22) → Remote login
• HTTP (Port 80) → Website access
• HTTPS (Port 443) → Secure website access

note: instance: inbound rules, security gtoup- edit inbound rules

Outbound Rules
--------------
Control outgoing traffic from the instance.
By default, AWS allows all outbound traffic.

Note
----
0.0.0.0/0 means "Anywhere" (all IPv4 addresses on the Internet).

Example:
SSH + 0.0.0.0/0
→ Anyone on the Internet can attempt to connect to your server via SSH
(if they have valid credentials).

In production, organizations typically restrict access to specific IP
addresses or VPN networks instead of using 0.0.0.0/0.

========================================================================================================================
Apache Web Server (httpd)
========================================================================================================================

Definition
----------
Apache is a web server that listens on Port 80 and serves web pages
(files) to browsers.

Package Name : httpd
Default Port : 80
Web Root     : /var/www/html

Why Apache?
-----------
A browser can display a website only if a web server responds to its
request. Apache receives the request and serves website files from:

/var/www/html


========================================================================================================================
========================================================================================================================
Install & Manage Apache
========================================================================================================================

Install Apache

sudo dnf install -y httpd

Note:
• httpd = Apache package name
• dnf = Linux package manager

Check Status

sudo systemctl status httpd

Press q to exit the status screen.

Start Apache

sudo systemctl start httpd

Stop Apache

sudo systemctl stop httpd

Restart Apache

sudo systemctl restart httpd

Enable Auto Start

sudo systemctl enable httpd

Note:
• Without enabling the service, Apache will not start automatically after
  an EC2 instance reboot.
• 'restart' is commonly used after configuration or website changes.
