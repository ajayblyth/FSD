# . What is destructuring?

Interview Answer:

Destructuring is an ES6 feature that allows us to extract values from arrays or properties from objects and store them directly into variables. It makes the code shorter and easier to read, especially when working with objects and arrays.

Object Destructuring:

const user = {
    name: "Ajay",
    age: 25,
    city: "Bangalore"
};

const { name, age, city } = user;

console.log(name); // Ajay
console.log(age);  // 25
console.log(city); // Bangalore

Here, instead of accessing user.name, user.age, etc. separately, we directly extract those properties into variables.

Array Destructuring:

const numbers = [10, 20, 30];

const [first, second, third] = numbers;

console.log(first);  // 10
console.log(second); // 20
console.log(third);  // 30

Array destructuring is based on position, while object destructuring is based on property name.

Important Points:

- Works with objects and arrays.
- Object destructuring uses { }.
- Array destructuring uses [ ].
- Object properties can be renamed while destructuring.
- Default values can also be provided.

Renaming:

const user = {
    name: "Ajay",
    age: 25
};

const { name: userName } = user;

console.log(userName); // Ajay

Here, the name property is stored in a variable called userName.

Default Value:

const { name, city = "Bangalore" } = user;

If city does not exist, "Bangalore" will be used as the default value.

# What is the spread operator?

Interview Answer:

The spread operator (...) is used to expand or unpack the elements of an array or the properties of an object into another array, object, or function call.

In simple terms, spread takes a collection of values and spreads those values out.

Array Example:

const numbers = [10, 20, 30];

const newNumbers = [...numbers, 40, 50];

console.log(newNumbers);
// [10, 20, 30, 40, 50]

Here, ...numbers expands the elements of numbers.

Copying an Array:

const numbers = [10, 20, 30];

const copy = [...numbers];

console.log(copy);
// [10, 20, 30]

This creates a shallow copy of the array.

Combining Arrays:

const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];

console.log(result);
// [1, 2, 3, 4]

Object Example:

const user = {
    name: "Ajay",
    age: 25
};

const updatedUser = {
    ...user,
    city: "Bangalore"
};

console.log(updatedUser);

// {
//     name: "Ajay",
//     age: 25,
//     city: "Bangalore"
// }

Spread can also be used to override an existing property.

const user = {
    name: "Ajay",
    age: 25
};

const updatedUser = {
    ...user,
    age: 26
};

console.log(updatedUser.age);
// 26

The later age: 26 overrides the earlier age value.

Spread can also be used when passing array elements as individual function arguments.

const numbers = [10, 20, 30];

console.log(Math.max(...numbers));
// 30

Important Points:

- Spread expands or unpacks values.
- Commonly used for copying and combining arrays and objects.
- It creates a shallow copy, not a deep copy.
- It can be used to pass array elements as individual function arguments.

# What is the rest operator?

Interview Answer:

The rest operator (...) is used to collect multiple values into a single array.

So, while spread expands values, rest collects values.

The same ... syntax is used, but its meaning depends on where it is used.

Function Example:

function sum(...numbers) {
    console.log(numbers);
}

sum(10, 20, 30, 40);

// [10, 20, 30, 40]

Here, all the arguments passed to the function are collected into the numbers array.

We can then use that array:

function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(10, 20, 30));
// 60

Rest with Array Destructuring:

const numbers = [10, 20, 30, 40];

const [first, second, ...remaining] = numbers;

console.log(first);     // 10
console.log(second);    // 20
console.log(remaining); // [30, 40]

Here, ...remaining collects all the remaining elements into an array.

Important Points:

- Rest collects multiple values into an array.
- It is commonly used with function parameters.
- It can also be used with array and object destructuring.
- A rest parameter must always be the last parameter.

Example:

function test(a, b, ...rest) {
    console.log(a);
    console.log(b);
    console.log(rest);
}

test(10, 20, 30, 40);

// 10
// 20
// [30, 40]

This is invalid:

function test(...rest, a) {} // Error

Because the rest parameter must be the last parameter.

# What is the difference between spread and rest operators?



Interview Answer:

Both use the same ... syntax, but their purpose is opposite.

Spread expands or unpacks values, while rest collects multiple values into a single array.

Spread Example:

const numbers = [10, 20, 30];

const copy = [...numbers];

console.log(copy);
// [10, 20, 30]

Here, ...numbers expands the array elements.

Rest Example:

function print(...numbers) {
    console.log(numbers);
}

print(10, 20, 30);

// [10, 20, 30]

Here, ...numbers collects the arguments into an array.


Difference:

Spread:
- Expands or unpacks values.
- Commonly used when copying or combining arrays and objects.
- Also used when passing array elements to a function.

Example:

const newArr = [...arr];


Rest:
- Collects multiple values into an array.
- Commonly used with function parameters.
- Also used with destructuring.

Example:

function test(...args) {}


Easy way to remember:

Spread → Spread things OUT

const arr = [1, 2, 3];

const newArr = [...arr];


Rest → Gather the REST together

function test(...args) {
    console.log(args);
}


Important Interview Point:

The ... syntax itself does not tell us whether it is spread or rest. The context determines its meaning.

const arr2 = [...arr1];       // Spread → expands

function test(...args) {}     // Rest → collects

const [a, ...rest] = arr;     // Rest → collects remaining values

ES6 / ECMAScript 2015 — Interview Notes

The first 7 topics below were already covered, so I’ll keep them brief. The remaining ES6 topics are explained a little more because they are new in this list.

let and const

let and const were introduced in ES6 to provide block-scoped variables.

let → value can be reassigned.

let age = 25;
age = 26;

const → variable cannot be reassigned.

const name = "Ajay";
// name = "Rahul";  // Error

Both are block-scoped and are hoisted but remain in the Temporal Dead Zone (TDZ) until their declaration is reached.

Arrow Functions (=>)

Arrow functions provide a shorter syntax for writing functions.

const add = (a, b) => a + b;

console.log(add(10, 20)); // 30

If there is only one parameter, parentheses can be omitted:

const square = n => n * n;

If the function has only one expression, {} and return can also be omitted. The expression is returned automatically.

const add = (a, b) => a + b;

With multiple statements, we need {} and an explicit return if we want to return a value.

const add = (a, b) => {
    const result = a + b;
    return result;
};

Important difference from normal functions: arrow functions don't have their own this; they inherit this from the surrounding lexical scope.

Template Literals

Template literals allow us to create strings using backticks ` and insert variables or expressions using ${}.

const name = "Ajay";
const age = 25;

console.log(`My name is ${name} and I am ${age} years old.`);

They are also useful for multi-line strings.

const message = `
Hello ${name},
Welcome to JavaScript.
`;
Default Parameters

Default parameters allow us to provide a default value when an argument is not passed or is undefined.

function greet(name = "Guest") {
    console.log(`Hello ${name}`);
}

greet();       // Hello Guest
greet("Ajay"); // Hello Ajay

This avoids manually checking whether a parameter was provided.

Rest Parameter (...)

The rest parameter collects multiple arguments into a single array.

function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(10, 20, 30)); // 60

Here, ...numbers collects all arguments into:

[10, 20, 30]

The rest parameter must always be the last parameter.

Spread Operator (...)

The spread operator expands or unpacks values from an array or object.

const numbers = [10, 20, 30];

const newNumbers = [...numbers, 40];

console.log(newNumbers);
// [10, 20, 30, 40]

It can also copy or combine objects:

const user = { name: "Ajay", age: 25 };

const updatedUser = {
    ...user,
    city: "Bangalore"
};

Spread creates a shallow copy.

Easy way to remember:

Rest   → collects values
Spread → expands values
Destructuring

Destructuring allows us to extract values from arrays or properties from objects directly into variables.

Object:

const user = {
    name: "Ajay",
    age: 25
};

const { name, age } = user;

Array:

const numbers = [10, 20, 30];

const [first, second, third] = numbers;

Object destructuring works by property name, while array destructuring works by position.

Enhanced Object Literals

Enhanced object literals provide shorter and more convenient syntax for creating objects.

Property shorthand

When the variable name and property name are the same, we can write the property only once.

const name = "Ajay";
const age = 25;

const user = {
    name,
    age
};

Instead of:

const user = {
    name: name,
    age: age
};
Method shorthand

We can define methods without writing the function keyword.

const user = {
    name: "Ajay",

    greet() {
        console.log("Hello");
    }
};

user.greet();

Instead of:

const user = {
    greet: function () {
        console.log("Hello");
    }
};

So enhanced object literals mainly make object creation cleaner and shorter.

Classes

ES6 introduced the class syntax to provide a cleaner way to create objects and implement inheritance.

class Person {
    constructor(name) {
        this.name = name;
    }

    greet() {
        console.log("Hello " + this.name);
    }
}

const person = new Person("Ajay");

person.greet(); // Hello Ajay

Here:

class       → defines the class
constructor → initializes object properties
new         → creates an object
greet()     → method

Classes support inheritance using extends and super.

class Student extends Person {
    study() {
        console.log("Studying");
    }
}

const student = new Student("Ajay");

student.greet(); // inherited from Person
student.study(); // Studying

Important interview point: JavaScript classes are built on top of the prototype-based inheritance mechanism we already discussed. They provide cleaner syntax, but JavaScript still uses prototypes internally.

Modules (import/export)

ES6 modules allow us to split JavaScript code into separate files and share functionality between them.

Named export

math.js

export function add(a, b) {
    return a + b;
}

Import:

import { add } from "./math.js";

console.log(add(10, 20));
Default export

user.js

export default function greet() {
    console.log("Hello");
}

Import:

import greet from "./user.js";

greet();

The main benefit is that modules keep code organized, reusable, and maintainable instead of putting everything into one large file.

Promises

A Promise represents the eventual result of an asynchronous operation.

It can be in three states:

Pending   → operation is still running
Fulfilled → operation completed successfully
Rejected  → operation failed

Example:

const promise = new Promise((resolve, reject) => {

    const success = true;

    if (success) {
        resolve("Data received");
    } else {
        reject("Something went wrong");
    }
});

promise
    .then(result => console.log(result))
    .catch(error => console.log(error));

Promises help us handle asynchronous operations without relying only on nested callbacks.

async/await provides a cleaner way to work with Promises.

for...of Loop

for...of is used to iterate over the values of an iterable, such as an array, string, Map, or Set.

const numbers = [10, 20, 30];

for (const number of numbers) {
    console.log(number);
}

Output:

10
20
30

With a string:

const name = "Ajay";

for (const char of name) {
    console.log(char);
}

Important distinction:

for...of → values
for...in → keys / property names

Example:

const numbers = [10, 20, 30];

for (const value of numbers) {
    console.log(value); // 10, 20, 30
}

for (const index in numbers) {
    console.log(index); // 0, 1, 2
}
