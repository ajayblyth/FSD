Why does only one card re-render?

Each UserCard receives these props:

user
selected
onSelect

When you click Select:

user → same object reference
onSelect → same function reference (useCallback)
selected → changes only for the clicked user (from false to true, and if another user was previously selected, that one changes back to false)

React.memo performs a shallow comparison of props. Since only the selected prop changes for the affected card(s), only those card(s) re-render. The rest keep the same prop references and are skipped.
