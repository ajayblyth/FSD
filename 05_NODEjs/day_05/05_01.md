=============================================================================

Objects store related data + behavior together.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let user = {
  name: "Ajay",
  age: 22,

  greet() {
    console.log("Hello");
  }
};

-----------------------------------------------------------------------------

• name, age      → properties
• greet()        → method

2. CONSTRUCTOR FUNCTIONS
=============================================================================

A constructor function is a special function used to create
multiple objects with same structure and behavior.

• Works like an object blueprint
• Used with new keyword
• Initializes object properties using this

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

function Person(name, age) {

  this.name = name;
  this.age  = age;
}

let p1 = new Person("Ajay", 25);


IMPORTANT
-----------------------------------------------------------------------------
• this.name means:
  store value inside object property called name

• name          → parameter
• this.name     → object property

=============================================================================
3. new KEYWORD
=============================================================================

new is a JavaScript keyword used to create objects from
constructor functions or classes.

-----------------------------------------------------------------------------
WHAT new DOES
-----------------------------------------------------------------------------

1. Creates empty object {}
2. Sets prototype link
3. Binds this → new object
4. Returns object automatically

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

function User(name) {
  this.name = name;
}

let u1 = new User("Ajay");

=============================================================================
THIS KEYWORD BEHAVIOR
=============================================================================

WITH new
-----------------------------------------------------------------------------
• this → newly created object

WITHOUT new
-----------------------------------------------------------------------------
• this → window/global object
OR undefined (strict mode)

4. FACTORY FUNCTION vs CONSTRUCTOR FUNCTION
=============================================================================

📌 FACTORY FUNCTION
=============================================================================

function Student(name, age, id) {

  return {

    name: name,
    age: age,
    id: id,

    getDetails: function() {
      console.log(this.name, this.age, this.id);
    }
  };
}

let s1 = Student("Nithin", 22, 12);

-----------------------------------------------------------------------------

CHARACTERISTICS
-----------------------------------------------------------------------------
• No new keyword
• Returns object manually
• Method recreated every object ❌
• Higher memory usage

=============================================================================
📌 CONSTRUCTOR FUNCTION + PROTOTYPE
=============================================================================


function Student(name, age, id) {

  this.name = name;
  this.age  = age;
  this.id   = id;
}

Student.prototype.getDetails = function() {

  console.log(this.name, this.age, this.id);
};

let s1 = new Student("Nithin", 22, 12);

-----------------------------------------------------------------------------

CHARACTERISTICS
-----------------------------------------------------------------------------
• Uses new keyword
• Object created automatically
• Shared methods using prototype ✅
• Memory efficient

=============================================================================
WHY NOT ARROW FUNCTION
=============================================================================

❌ Wrong
-----------------------------------------------------------------------------

Student.prototype.getDetails = () => {

  console.log(this.name);
};

-----------------------------------------------------------------------------

• Arrow functions do not have own this
• Takes this from outer scope
• this.name becomes undefined

-----------------------------------------------------------------------------
✔ Correct
-----------------------------------------------------------------------------
Use normal function for prototype methods.
=============================================================================
HOW METHOD LOOKUP WORKS
=============================================================================

s1.getDetails()

1. JS checks inside s1
2. Not found
3. Checks Student.prototype
4. Finds method
5. Executes with this = s1

=============================================================================
KEY DIFFERENCE
=============================================================================

FACTORY FUNCTION
-----------------------------------------------------------------------------
• Method duplicated every object ❌

CONSTRUCTOR + PROTOTYPE
-----------------------------------------------------------------------------
• Method shared among objects ✅

5. ES6 CLASSES
=============================================================================

DEFINITION
-----------------------------------------------------------------------------
Cleaner syntax over constructor + prototype.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

class Person {

  constructor(name, age) {

    this.name = name;
    this.age  = age;
  }

  greet() {  //function keyword is not allowed in a class body.

    console.log("Hello " + this.name);
  }
}

const p1 = new Person("Ajay", 22);

p1.greet();


-----------------------------------------------------------------------------

IMPORTANT
-----------------------------------------------------------------------------
• Methods internally stored in Person.prototype
=============================================================================
MULTIPLE OBJECTS USING MAP
=============================================================================

const data = [
  ["Ajay",   22],
  ["Vijay",  25],
  ["Suresh", 30]
];

const users = data.map(
  d => new Person(d[0], d[1])
);  // map collects every return value into a new array

users.forEach(u => u.greet());

6. INHERITANCE (extends + super)
=============================================================================

KEYWORDS
-----------------------------------------------------------------------------
extends → inherit parent class
super   → call parent constructor

=============================================================================
PARENT CLASS
=============================================================================

class Person {

  constructor(name, age) {

    this.name = name;
    this.age  = age;
  }

  greet() {

    console.log("Hello " + this.name);
  }
}

=============================================================================
CHILD CLASS
=============================================================================

class Student extends Person {

  constructor(name, age, marks) {

    super(name, age);

    this.marks = marks;
  }

  showMarks() {

    console.log(
      this.name + " has " + this.marks + " marks"
    );
  }
}

=============================================================================
USAGE
=============================================================================

const s1 = new Student("Ajay", 22, 90);

s1.greet();

s1.showMarks();

-----------------------------------------------------------------------------

IMPORTANT NOTE
-----------------------------------------------------------------------------
• name and marks are object properties
• Access using this.name, this.marks

7. PROTOTYPE BASICS
=============================================================================

DEFINITION
-----------------------------------------------------------------------------
• Prototype is an object from which other objects inherit
  properties and methods.

• Every JS object has internal prototype link.

• If property/method not found in object,
  JS checks prototype.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let obj = { name: "Ajay" };

console.log(obj.__proto__);

→ points to Object.prototype

=============================================================================
ADVANTAGES OF PROTOTYPE
=============================================================================

• Memory efficient
• Shared methods
• Code reuse
• Supports inheritance
• Dynamic method addition
• Base of JS OOP system

=============================================================================
7.1  WHY PROTOTYPES EXIST IN JAVASCRIPT
=============================================================================

PROBLEM WITHOUT PROTOTYPES
-----------------------------------------------------------------------------
Suppose we create 1000 user objects:

function User(name) {

  this.name = name;

  this.greet = function() {
    console.log("Hello");
  };
}

-----------------------------------------------------------------------------
ISSUE
-----------------------------------------------------------------------------
• Every object gets separate copy of greet()
• Huge memory waste
• Duplicate methods

-----------------------------------------------------------------------------
SOLUTION = PROTOTYPE
-----------------------------------------------------------------------------

function User(name) {

  this.name = name;
}

User.prototype.greet = function() {

  console.log("Hello" + this.name);
};

-----------------------------------------------------------------------------
NOW
-----------------------------------------------------------------------------
• greet() exists only once in memory
• All objects share same method
• JS finds method using prototype chain

=============================================================================
WHY JAVASCRIPT USES PROTOTYPES
=============================================================================

JavaScript was originally designed as:
• lightweight
• dynamic
• flexible

Instead of copying methods into every object,
JS links objects together using prototypes.

-----------------------------------------------------------------------------
CLASS-BASED LANGUAGE (JAVA)
-----------------------------------------------------------------------------
Object copies behavior from class blueprint.

-----------------------------------------------------------------------------
JAVASCRIPT
-----------------------------------------------------------------------------
Objects directly inherit from other objects
using prototype links.

-----------------------------------------------------------------------------
THAT IS WHY JAVASCRIPT IS CALLED
-----------------------------------------------------------------------------
“Prototype-based language”

=============================================================================
REAL INTERNAL IDEA
=============================================================================

When object cannot find method inside itself:

1. JS checks prototype object
2. If found → uses shared method
3. Else → continues prototype chain

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let arr = [1,2,3];

arr.push(4);

-----------------------------------------------------------------------------
QUESTION
-----------------------------------------------------------------------------
Where did push() come from?

-----------------------------------------------------------------------------
ANSWER
-----------------------------------------------------------------------------
arr does not contain push directly.

JS internally does:

arr → Array.prototype → push()

-----------------------------------------------------------------------------
THAT IS WHY BUILT-IN METHODS WORK
-----------------------------------------------------------------------------
• map()
• filter()
• push()
• toUpperCase()
• slice()

All come from prototypes.

=============================================================================
MOST IMPORTANT UNDERSTANDING
=============================================================================

Prototype is NOT copying methods.

Prototype is LINKING objects.

-----------------------------------------------------------------------------
WITHOUT PROTOTYPE
-----------------------------------------------------------------------------
Each object stores duplicate methods.

-----------------------------------------------------------------------------
WITH PROTOTYPE
-----------------------------------------------------------------------------
Objects share methods through links.

=============================================================================
INTERVIEW UNDERSTANDING
=============================================================================

“Prototype is JavaScript’s inheritance mechanism that allows
objects to share methods and properties through prototype links,
improving memory efficiency and enabling code reuse.”

=============================================================================

Note: 
• When JS creates a function, it automatically creates:
  ConstructorFunction.prototype = {}
  ex. User.prototype= {}

• When new creates object, JS automatically links:
  obj.__proto__ = ConstructorFunction.prototype

• So objects inherit shared methods from prototype object

• Relation:
  obj.__proto__ === ConstructorFunction.prototype

8. __proto__ vs prototype vs constructor
=============================================================================

These are the MOST confusing JS OOP terms initially.

Simple understanding:
-----------------------------------------------------------------------------
__proto__   → exists inside OBJECTS
prototype   → exists inside FUNCTIONS
constructor → reference to creator function

=============================================================================
📌 prototype (FUNCTION LEVEL)
=============================================================================

prototype is a NORMAL OBJECT attached automatically to
functions/classes.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

function User() {}

-----------------------------------------------------------------------------
JS internally creates
-----------------------------------------------------------------------------

User.prototype = {}

-----------------------------------------------------------------------------
IMPORTANT
-----------------------------------------------------------------------------
• Only functions/classes have .prototype
• Used to store shared methods/properties
• All objects created using constructor share this object

-----------------------------------------------------------------------------
ADDING METHOD
-----------------------------------------------------------------------------

User.prototype.greet = function() {

  console.log("Hello");
};

-----------------------------------------------------------------------------
NOW User.prototype CONTAINS
-----------------------------------------------------------------------------

{
   greet: function() {}
}

=============================================================================
📌 __proto__ (OBJECT LEVEL)
=============================================================================

__proto__ is a hidden link inside every object.

-----------------------------------------------------------------------------
PURPOSE
-----------------------------------------------------------------------------
• Used for inheritance lookup
• Points to parent/shared prototype object

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let u1 = new User();

-----------------------------------------------------------------------------
INTERNALLY
-----------------------------------------------------------------------------

u1.__proto__ = User.prototype

-----------------------------------------------------------------------------
MEANING
-----------------------------------------------------------------------------
u1 is LINKED to User.prototype

• Methods are NOT copied
• JS searches through this link

=============================================================================
VISUAL FLOW
=============================================================================

FUNCTION SIDE
-----------------------------------------------------------------------------
function User() {}

User.prototype = {
   greet: function() {}
}

OBJECT SIDE
-----------------------------------------------------------------------------
let u1 = new User();

u1.__proto__ ---------> User.prototype

-----------------------------------------------------------------------------
IMPORTANT UNDERSTANDING
-----------------------------------------------------------------------------
prototype   = actual shared object
__proto__   = link pointing to shared object

C) KEY DIFFERENCE TABLE
========================================================

Feature        | prototype              | __proto__
--------------------------------------------------------
Exists on      | Functions             | Objects
Purpose        | Define shared methods | Link to prototype
Usage          | Constructor setup     | Inheritance lookup
Direct use     | Yes                   | Not recommended

=============================================================================
📌 constructor
=============================================================================

constructor is reference to function that created object.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

function User() {}

let u1 = new User();

u1.constructor === User

=============================================================================
RELATION BETWEEN ALL THREE
=============================================================================

u1 → __proto__ → User.prototype → constructor → User

-----------------------------------------------------------------------------
FLOW
-----------------------------------------------------------------------------
• Object’s __proto__ points to function’s prototype
• prototype contains constructor pointing back to function

=============================================================================
WHY "FUNCTION LEVEL" ?
=============================================================================

function User() {}

-----------------------------------------------------------------------------
VALID
-----------------------------------------------------------------------------

User.prototype

-----------------------------------------------------------------------------
INVALID
-----------------------------------------------------------------------------

let obj = {}

obj.prototype   // undefined

-----------------------------------------------------------------------------
REASON
-----------------------------------------------------------------------------
Because obj is normal object, not constructor function.

=============================================================================
WHY "OBJECT LEVEL" ?
=============================================================================

Objects contain hidden inheritance link:

obj.__proto__

-----------------------------------------------------------------------------
Used by JS to search methods/properties in parent object.
-----------------------------------------------------------------------------

=============================================================================
SIMPLE ANALOGY
=============================================================================

constructor → factory
prototype   → shared toolbox
__proto__   → wire/link to toolbox

=============================================================================
INTERVIEW ONE-LINE
=============================================================================

“prototype is the shared object attached to constructor functions,
__proto__ is the hidden link inside objects pointing to that prototype,
and constructor refers to the function that created the object.”

9. PROTOTYPE CHAIN
=============================================================================

LOOKUP FLOW
-----------------------------------------------------------------------------

obj → obj.__proto__ → Object.prototype → null

=============================================================================
STEP FLOW
=============================================================================

1. JS checks object itself
2. If not found → checks prototype
3. If still not found → Object.prototype
4. If nowhere found → undefined

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let arr = [1,2,3];

arr.push(4);

• push() not inside arr directly
• JS finds push() inside Array.prototype

=============================================================================
FINAL UNDERSTANDING
=============================================================================

• Object itself may not contain method
• JS searches prototype chain
• This is prototype inheritance

10. PROTOTYPE SHARING & MEMORY OPTIMIZATION
=============================================================================

❌ WITHOUT PROTOTYPE
=============================================================================

let arr1 = [1,2,3];
let arr2 = [4,5,6];

arr1.sayHello = function() {

  console.log("Hello");
};

arr1.sayHello();

arr2.sayHello();   // ERROR

-----------------------------------------------------------------------------
PROBLEM
-----------------------------------------------------------------------------
• Method duplicated
• Memory waste

=============================================================================
✔ WITH PROTOTYPE
=============================================================================

Array.prototype.sayHello = function() {

  console.log("Hello from prototype");
};

arr1.sayHello();

arr2.sayHello();

-----------------------------------------------------------------------------
HOW IT WORKS
-----------------------------------------------------------------------------

arr1 → Array.prototype → Object.prototype → null

arr2 → Array.prototype → Object.prototype → null

-----------------------------------------------------------------------------
ADVANTAGES
-----------------------------------------------------------------------------
• Shared methods
• No duplication
• Memory efficient

11. Object.create()
=============================================================================

DEFINITION
-----------------------------------------------------------------------------
Creates object with direct prototype linking.

-----------------------------------------------------------------------------
EXAMPLE
-----------------------------------------------------------------------------

let person = {

  greet() {

    console.log("Hello");
  }
};

let user = Object.create(person);

user.greet();

let employee = {
  
  greet(name){
    this.name = name
    console.log("Hello" + this.name);
  }
}
let user = Object.create(employee);
user.greet("Ajay")

-----------------------------------------------------------------------------
IMPORTANT
-----------------------------------------------------------------------------
• user is empty object
• linked to personPrototype

12. Object.getPrototypeOf()
=============================================================================

DEFINITION
-----------------------------------------------------------------------------
Returns immediate/direct prototype of object.

-----------------------------------------------------------------------------
IMPORTANT
-----------------------------------------------------------------------------
• Only direct parent returned
• Not full prototype chain

-----------------------------------------------------------------------------
SYNTAX
-----------------------------------------------------------------------------
Object.getPrototypeOf(value)

=============================================================================
WAYS TO ACCESS PROTOTYPE
=============================================================================

1. __proto__
2. Object.getPrototypeOf()
3. Object.setPrototypeOf()

=============================================================================
WHY Object.getPrototypeOf() IS PREFERRED
=============================================================================

• __proto__ is old accessor property
• Can be modified/tampered

-----------------------------------------------------------------------------
Object.getPrototypeOf()
-----------------------------------------------------------------------------
✔ Standard
✔ Reliable
✔ Safer

=============================================================================
EXAMPLE 1 (STRING)
=============================================================================

let str = "hello";

console.log(Object.getPrototypeOf(str));

→ String.prototype

=============================================================================
EXAMPLE 2 (ARRAY)
=============================================================================

let arr = [1,2,3];

console.log(Object.getPrototypeOf(arr));

→ Array.prototype
