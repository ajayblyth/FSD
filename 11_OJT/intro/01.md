# OJT — On-the-Job Training

## 1. What is OJT?

**OJT = On-the-Job Training**

OJT is the stage where you apply what you learned during training to real-world projects.

### During OJT, you will:

* Apply your training knowledge to real projects
* Build applications from requirements → implementation
* Work with:

  * Frontend
  * Backend
  * Database
  * Git/GitHub
* Learn to solve problems independently
* Work as part of a development team

> **Training is where you learn. OJT is where you build.**

---

## 2. Why Are We Doing OJT?

The main goal is to understand how real software development works.

### Understand

* Requirements
* Business problems

### Plan

* Features
* Database
* APIs
* UI

### Build

* Frontend
* Backend
* Database

### Debug

* Find issues
* Understand errors
* Solve problems

### Collaborate

* Discuss with the team
* Review code
* Help teammates
* Learn from others

### Explain

* Understand your implementation
* Be able to explain why and how you implemented it

> **The goal is not just to complete the project. The goal is to understand what you build.**

---

## 3. How Will OJT Work?

### Team Project

* Each team works together on the same project.
* Everyone contributes to the project.

### Individual Coding

* Everyone writes their own code.
* Each person works on assigned features/tasks.

### Team Learning

* Discuss problems
* Review each other's work
* Help teammates
* Learn from each other

### Important Rules

* Everyone should understand the complete project.
* No copy-pasting another person's implementation.
* Everyone should be able to explain their own work.

> **Work as a team, but learn and code individually.**

---

---

## 5. Daily OJT Connect

### Every Evening

There will be a daily call to discuss progress and blockers.

### Discuss

**Completed**

* What did you finish today?

**In Progress**

* What are you currently working on?

**Blocked**

* What problem are you facing?

**Next**

* What will you work on next?

### Expectations

* Raise blockers early
* Ask questions
* Share learnings
* Plan the next step

> **Daily updates are for progress, learning and problem solving.**

---

## 6. OJT Expectations

### 1. Understand Before Implementing

* First understand the requirement.
* Then decide how to implement it.

### 2. Code Your Own Work

* Avoid copy-paste implementations.
* Understand the code you write.

### 3. Try to Debug Yourself

* First investigate the problem.
* Try possible solutions.
* Then ask for help if needed.

### 4. Test What You Build

* Test your APIs/features.
* Check different scenarios.
* Fix issues before considering the task complete.

### 5. Use Git/GitHub Properly

* Commit your work regularly.
* Use meaningful commit messages.
* Work with branches properly.
* Push your changes.

### 6. Keep the Team Updated

* Share your progress.
* Raise blockers early.
* Communicate when you need help.

### 7. Be Ready to Explain

You should be able to explain:

* What you implemented
* Why you implemented it that way
* How it works
* What problems you faced
* How you solved them

---

## 7. Main OJT Mindset

> **Work as a team.**
> **Code individually.**
> **Learn continuously.**
> **Understand what you build.**
