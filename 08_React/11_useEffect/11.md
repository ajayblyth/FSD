# React - useEffect Hook


What is useEffect?
==================

A React component's primary responsibility is to **take data (props/state) and return JSX (UI).**

Here's what each part means:
Component → A JavaScript function that returns JSX.
Props → Data passed from a parent component.
State → Data owned and managed by the component (created using useState).

Anything other than rendering the UI is called a **Side Effect**.

Examples of Side Effects:

* API calls
* Timers (`setTimeout`, `setInterval`)
* Event listeners
* Updating the document title
* Accessing Local Storage
* WebSocket connections
* Subscriptions

React provides the **useEffect** Hook to perform these side effects.

Note:A Hook is a special built-in React function that lets functional components use React features like state, side effects, context, and refs.
A functional component is a JavaScript function that can accepts props as input and returns JSX to render the UI.
---

## Syntax

useEffect(() => {

    // Side Effect

}, [dependencies]);

The second argument is called the **Dependency Array**.

It tells React:  **"Run this effect only when these values change."**

# Case 1 : No Dependency Array
useEffect(() => {
    console.log("Running...");
});


### What happens?

Since no dependency array is provided, React executes the effect **after every render**.

Example

const [count, setCount] = useState(0);

useEffect(() => {
    console.log("useEffect");
});

Whenever the component renders:

✅ Initial render

✅ Click Increment

✅ Click Increment again

✅ Any state change

Output:
useEffect
useEffect
useEffect
...

Sometimes this is unnecessary because every render executes the effect again.
---

# Case 2 : Empty Dependency Array

useEffect(() => {
    console.log("Called Once");
}, []);


### What does [] mean?

It means

> **"Watch for nothing."**

Since React has nothing to watch, the effect executes **only once**, after the component mounts (initial render).

Output: Called Once

Even if the component re-renders later, this effect will not execute again.

---
# Case 3 : Dependency Array with State

const [count, setCount] = useState(0);
const [toggle, setToggle] = useState(false);

useEffect(() => {
    console.log("Count Changed");
}, [count]);

React now watches only **count**.

When **count** changes, useEffect runs

When **toggle** changes, nothing happens

because toggle is not present inside the dependency array.

---

## Multiple Dependencies

useEffect(() => {
    console.log("Something Changed");
}, [count, toggle]);

Now React watches both values. 
Whenever **count** OR **toggle** changes, the effect executes again.
---

# Why Dependency Array?

Without dependency array


Every Render

With [] : Only Once

With [count] : Whenever count changes

With [count, toggle] : Whenever count or toggle changes

Case 4 : Cleanup Function
=========================
Note:  Mount: A component is created and added to the DOM (screen) for the first time.

Unmount: A component is removed from the DOM (screen). React runs the cleanup function during unmount if one is returned from useEffect.

The cleanup function is used to remove or stop resources created by useEffect when they are no longer needed. It helps prevent memory leaks, improve performance, and avoid duplicate event listeners, timers, or open connections. React runs the cleanup before the effect runs again and when the component unmounts.

* Event listeners
* Timers
* Intervals
* WebSocket connections
* Subscriptions

These should be removed when they are no longer required.

For this React provides a **Cleanup Function**.

useEffect(() => {

    console.log("Adding Event Listener");

    return () => {

        console.log("Removing Event Listener");

    };

}, []);

The function returned from useEffect is called the **Cleanup Function**.

---

## Example : Removing Event Listener

useEffect(() => {

    function resizeHandler() {
        console.log("Window Resized");
    }

    window.addEventListener("resize", resizeHandler);

    return () => {

        console.log("Removing Event Listener");

        window.removeEventListener("resize", resizeHandler); //"Stop listening for the resize event. Don't call resizeHandler anymore."

    };

}, []);

When the component unmounts

Removing Event Listener

The event listener gets removed.

---

## Why Cleanup?

Cleanup helps

* Prevent memory leaks
* Improve performance
* Stop unnecessary background work
* Remove event listeners
* Clear timers
* Close open connections

Examples

clearTimeout()

clearInterval()

window.removeEventListener()

socket.close()

React Strict Mode
=================

Sometimes in development you may see

Component Rendered
Component Rendered

or

useEffect
useEffect

This happens because **React Strict Mode intentionally renders components twice during development**.

Purpose

* Detect side effects
* Detect memory leaks
* Verify cleanup logic

This does **NOT** happen in production.

---

# Summary

| Dependency Array | When useEffect Runs                               |
| ---------------- | ------------------------------------------------- |
| No array         | After every render                                |
| []               | Only once after initial render                    |
| [count]          | Initial render + whenever count changes           |
| [count, toggle]  | Initial render + whenever count or toggle changes |

---

# Flow

Component Renders
        ↓
React Checks Dependency Array
        ↓
No Dependency Array?
        ↓
Run After Every Render

OR

Empty Dependency Array?
        ↓
Run Only Once

OR

Dependencies Present?
        ↓
Run When Dependency Changes
        ↓
Cleanup Executes (Before next run / Unmount)
        ↓
Run Effect Again
