Returning Multiple Elements in React

Rule:
A React component must return only ONE
parent/root element.

You cannot return multiple elements
side-by-side directly.

--------------------------------------------------

Wrong:

return (
    <h1>Hello</h1>
    <h1>World</h1>
)

--------------------------------------------------

Correct Method 1 : Wrap inside <div>

return (
    <div>
        <h1>Hello</h1>
        <h1>World</h1>
    </div>
)

--------------------------------------------------

Correct Method 2 : Use Fragment

return (
    <>
        <h1>Hello</h1>
        <h1>World</h1>
    </>
)

--------------------------------------------------

Fragment:
- Groups multiple elements together
- Does NOT create extra HTML tags in DOM
- Cleaner than unnecessary <div>
