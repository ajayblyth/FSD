REACT:
- JavaScript library created by Meta
- Used for building UI (User Interface)
- Mainly used for Single Page Applications (SPA)
- React focuses only on UI layer

Main Advantage:
- We don't refresh the whole page for small changes
- React updates only the changed part of the page
- Makes apps faster and smoother

Example:
Changing like count, chat message, notification etc. does not reload entire webpage.

================================================================================

Why React Became Popular

Problems in Traditional DOM Manipulation:

1. Manual DOM Updates
   Developers had to use:
   document.getElementById()
   innerHTML
   appendChild()

2. Code Became Messy
   HTML, CSS, JS scattered everywhere.

3. Difficult State Management
   Keeping UI synced with data became hard.

4. Full Page Re-rendering
   Small changes could refresh large parts of page.

5. Reusability Problem
   Same UI repeated again and again.

================================================================================

How React Solves These Problems

1. Component-Based Architecture
   UI is divided into reusable components.

   Example:
   - Navbar, Sidebar, Card, Footer

   Each component has:
   - its own UI
   - logic
   - styling

Simple Component Idea:

Page
|
|-- Navbar
|-- Sidebar
|-- ProductCard
|-- Footer

================================================================================

2. Declarative UI

In normal JS:
- We manually tell browser WHAT to change.

In React:
- We describe HOW UI should look.
- React handles updates automatically.

================================================================================

3. Virtual DOM

React creates a lightweight copy of real DOM inside memory called Virtual DOM.

When data changes:
1. React creates new virtual DOM
2. Compares old vs new (diffing)
3. Updates only changed elements

This makes React fast.

================================================================================

4. Unidirectional Data Flow

Data flows:

Parent  --->  Child

using Props.

Benefits:
- predictable
- easier debugging
- cleaner structure

================================================================================

JSX (JavaScript XML / Extension Syntax)

JSX allows writing HTML inside JavaScript.

Example:

const element = <h1>Hello</h1>;

Without JSX:

const element = React.createElement("h1", null, "Hello");

Benefits of JSX:
- cleaner syntax
- easier to read
- HTML-like structure
- easier UI building

================================================================================

Babel and JSX

Browsers cannot understand JSX directly.

Babel:
- JavaScript transpiler/compiler
- Converts JSX into normal JavaScript

Flow:
1. You write JSX
2. Babel reads JSX
3. Babel converts to JS
4. Browser executes JS

Example:

JSX:
const el = <h1>Hello</h1>;

After Babel:

const el = React.createElement("h1", null, "Hello");
JSX becomes plain javascript with react createElement calls.

createRoot()

In normal DOM:

const h1 = document.createElement("h1");
h1.innerText = "Hello";
document.body.appendChild(h1);

In React:

const root = ReactDOM.createRoot(document.getElementById("root")); //It creates a React Root object and attaches React to an existing DOM element.

root.render(<App />);

Explanation:
- createRoot() creates React root container
- render() displays React components inside root div
- React handles DOM updates automatically

Usually inside index.html:

<div id="root"></div>

React injects entire app inside this div.

APP COMPONENT IN REACT
======================

What is App?
------------
App is a React Component.

Example:

function App() {
    return (
        <h1>Hello React</h1>
    );
}

export default App;


What happens internally?
------------------------

root.render(<App />);

React sees:

<App />

and internally executes:

App();

App returns:

<h1>Hello React</h1>

React converts it into DOM and renders it inside:

<div id="root"></div>


Result:

<div id="root">
    <h1>Hello React</h1>
</div>


Real Project Example
--------------------

App.jsx

import Header from "./components/Header";
import Home from "./components/Home";

function App() {

    return (
        <>
            <Header />
            <Home />
        </>
    );
}

export default App;


Header.jsx

function Header() {
    return <h1>My Website</h1>;
}

export default Header;

    return <p>Welcome User</p>;

export default Home;

Interview Question

Q. What is App in root.render(<App />)?

A.
- App is the root React component.
- Usually defined in App.jsx.
- React starts rendering from App.
- App contains other components.
- Entire component tree begins from App.

      App Component
