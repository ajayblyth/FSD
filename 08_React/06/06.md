React Redux Notes
=================

1. Install Packages
-------------------

Previous Class:

npm i redux

- Core Redux library
- Works with plain JavaScript
- Creates Store, Reducers, Actions

Today:

npm i react-redux

- Connects Redux with React
- Provides:
  * Provider
  * useSelector
  * useDispatch

Keep BOTH packages installed.

redux        -> State management engine
react-redux  -> React integration layer


2. Configure Store
------------------

store.js

Create and export store:

export const store = createStore(reducer);


3. Connect Redux To React
-------------------------

main.jsx

Import:

import { Provider } from "react-redux";
import { store } from "./store";

Wrap App:

<Provider store={store}>
  <App />
</Provider>

Provider makes Redux store available
to all React components.


4. Reading Data From Store
--------------------------

Account.jsx

Old Redux:

store.getState()

React Redux:

import { useSelector } from "react-redux";

const data = useSelector((state) => {
  return state;
});

useSelector:
- Reads state
- Subscribes to store
- Auto re-renders on state change

No manual update required.

7. Problem With Direct Dispatch
-------------------------------

Example:

dispatch({
  type: "deposit",
  payload: amount
});

Same structure repeated everywhere.

Examples:
- ATM Withdrawal
- UPI Withdrawal
- Net Banking Withdrawal

Creates repetitive code.


8. Action Creators
------------------

actions.js

Action Creator:
Function that returns an action object.

Example:

export const deposit = (amount) => {
  return {
    type: "deposit",
    payload: amount
  };
};

Usage:

dispatch(deposit(amount));

Benefits:
- Centralized logic
- Less repetition
- Easy maintenance
- Cleaner code

Also create:

withdraw()
setProfile()
reset()


9. Multiple Reducers
--------------------

Bad Practice:

One huge reducer for everything.

Good Practice:

accountReducer
transactionReducer
profileReducer


10. combineReducers
-------------------

Cannot pass multiple reducers directly.

Import:

import { combineReducers } from "redux";

Example:

const rootReducer = combineReducers({
  account: accountReducer,
  transactions: transReducer
});

Create Store:

const store = createStore(rootReducer);

----------------------

Account Data:

const data = useSelector((state) => {
  return state.account;
});

Transactions:

const transactions = useSelector((state) => {

});

Previously:

Now:

return state.account;
return state.transactions;
