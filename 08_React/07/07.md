Redux Thunk (Async Redux)
=========================

1. Problem With Normal Redux
----------------------------

Till now we handled only synchronous actions.

Example:

dispatch({
  type: "deposit",
  payload: 1000
});

Works because dispatch accepts
a plain JavaScript object.

Problem:

API calls are asynchronous.

Example:

fetch(...)
axios.get(...)

Dispatch cannot directly handle:

dispatch(async () => {})

This is where Thunk comes in.


2. What Is Thunk?
----------------

Thunk is a Redux middleware.

Middleware sits between:

Dispatch
   |
   v
Middleware (Thunk)
   |
   v
Reducer

Responsibilities:

- Handles async operations
- Gives access to dispatch
- Gives access to getState
- Allows API calls before reaching reducer

Thunk receives:

dispatch
getState


3. Thunk Function Structure
---------------------------

Thunk returns another function.

Two functions exist:

Outer Function
   |
   v
Inner Function

Example:

const fetchUser = (userId) => {

  return async (dispatch, getState) => {

  };

};

Outer Function:
- Receives user input

Inner Function:
- Performs async work
- Receives dispatch
- Receives getState

6. Create User Reducer
----------------------

Create:

userReducer

Purpose:

Handle all promise states.

Three states:

1. Loading
2. Success
3. Failure

Initial State:

{
  loading: false,
  user: null,
  error: null
}

Use switch case:

userReducer(state = initialState, action)

Cases:

FETCH_USER_START
FETCH_USER_SUCCESS
FETCH_USER_FAIL


7. Create Async Actions
-----------------------

File:

actions_async.js

Create three action creators.

fetchUserStart()

Returns:

{
  type: "FETCH_USER_START"
}


fetchUserSuccess(data)

Returns:

{
  type: "FETCH_USER_SUCCESS",
  payload: data
}


fetchUserFail(error)

Returns:

{
  type: "FETCH_USER_FAIL",
  payload: error
}


8. Create Thunk Action Creator
------------------------------

This action creator returns
another function.

Outer Function:

fetchUser(userId)

Inner Function:

async (dispatch, getState)

Example Flow:

export const fetchUser = (userId) =>
  async (dispatch, getState) => {

    dispatch(fetchUserStart());

    try {

      const res = await fetch(
        `https://jsonplaceholder.typicode.com/users/${userId}`
      );

      const data = await res.json();

      dispatch(
        fetchUserSuccess(data)
      );

    } catch(error) {

      dispatch(
        fetchUserFail(error.message)
      );

    }

};

Process:

1. Loading starts
2. API called
3. Data received
4. Success dispatched

OR

1. Loading starts
2. API fails
3. Error dispatched

--------------------

  }

11. Show Loading State
----------------------

  <p>Loading...</p>
}

Visible while API request
is in progress.


12. Show Error State
--------------------

  </p>
}

Visible if API fails.

Final Summary
-------------

Synchronous Redux:

Component
   |
   v
dispatch(action)
   |
   v
Reducer
   |
   v
Store
   |
   v
useSelector

Async Redux With Thunk:

Component
   |
   v
dispatch(fetchUser())
   |
   v
Thunk Middleware
   |
   v
API Call
   |
   +------> Success -----> Reducer
   |
   +------> Error -------> Reducer
                            |
                            v
                          Store
                            |
                            v
                      useSelector
                            |
                            v
                     Component Re-renders
