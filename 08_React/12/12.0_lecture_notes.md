=========================================================================================
React Performance Hooks - useRef & useMemo
=========================================================================================

Problem
-------
React re-renders when:
- State changes in a component.
- Props change.
- Parent component re-renders (child components also re-render).

During every render:
- Variables are recreated.
- Functions are recreated.
- Calculations run again.
- New objects and functions are created every time.

How to resolve this?
--------------------
On every render, everything is rebuilt. To optimize this, React provides:

- useRef
- useMemo
- useCallback
- React.memo (Higher Order Component - not covered yet, just know it exists.)

=========================================================================================
1. useRef
=========================================================================================

Definition
----------
useRef is like a box that survives re-renders and never triggers a re-render, unlike useState.

Important:
The useRef object itself is created only once.
On every render, React returns the same object.

Only .current changes.

Syntax

const myRef = useRef(initialValue);

It always returns an object with a property called .current.

Access value using: myRef.current

Example:
const myRef = useRef("Hello");

React internally returns something like:

const myRef = {
  current: "Hello"
};

Note:
-----
- Updating myRef.current silently changes the value without rendering the component.
- Use useRef for values changing in the background (not displayed in UI).
- Use useState when changing the value should update the UI.

Examples:
- Previous value
- Timer ID
- DOM elements
- Focus input

-----------------------------------------------------------------------------------------
RenderCounter Example
-----------------------------------------------------------------------------------------

Create:

src/
└── useRef/
    └── RenderCounter.jsx

```jsx
import React, { useState, useEffect, useRef } from "react";

const RenderCounter = () => {
  const [text, setText] = useState("");
  const renderCount = useRef(1);

  // Using state here would cause:
  // render -> setState -> render -> setState -> infinite loop
  useEffect(() => {
    renderCount.current = renderCount.current + 1;
  });

  return (
    <div>
      <input
        type="text"
        value={text}
        onChange={(e) => setText(e.target.value)}
      />

      <h3>Typing: {text}</h3>
      <h3>Component rendered {renderCount.current} times</h3>
    </div>
  );
};

export default RenderCounter;

Focus Input Example
-----------------------------------------------------------------------------------------

Purpose:
--------
Use useRef to focus a DOM element.

Create:

src/
└── useRef/
    └── FocusInput.jsx

import React, { useRef } from "react";

const FocusInput = () => {
  const inputRef = useRef(null);

  const handleFocus = () => {
    inputRef.current.focus();
  };

  return (
    <div>
      <input
        ref={inputRef}
        type="text"
        placeholder="Click the button"
      />

      <button onClick={handleFocus}>
        Focus Input
      </button>
    </div>
  );
};

export default FocusInput;
```

Stopwatch Example
-----------------------------------------------------------------------------------------

Create:

src/
└── useRef/

```jsx
const Stopwatch = () => {

  const [seconds, setSeconds] = useState(0);

  const timerId = useRef(null);

  const start = () => {

    if (timerId.current !== null) return;

    timerId.current = setInterval(() => {
      setSeconds((prev) => prev + 1);
    }, 1000);
  };

  const stop = () => {
    clearInterval(timerId.current);
    timerId.current = null;
  };

  const reset = () => {
    stop();
    setSeconds(0);
  };

  useEffect(() => {
    return () => clearInterval(timerId.current);
  }, []);
};
```

2. useMemo
=========================================================================================

Definition
----------
Don't redo an expensive calculation.

Instead, remember (cache) the previous result and only recalculate when the dependency changes.

Syntax

```jsx
const value = useMemo(() => {
  return expensiveCalculation();
}, [dependency]);
```

Create:

src/
└── useMemo/
    └── SlowEx.jsx

Import it in App.jsx.

-----------------------------------------------------------------------------------------
Slow Example
-----------------------------------------------------------------------------------------

```jsx
import React, { useMemo, useState } from "react";

const slowDouble = (num) => {
  console.log("Running the slow calc");

  const start = Date.now();

  while (Date.now() - start < 1000) {}

  return num * 2;
};

const SlowEx = () => {

  const [number, setNumber] = useState(1);
  const [dark, setDark] = useState(false);

  // const doubled = slowDouble(number); //problem:This runs on every render, even when only the theme changes.

  const doubled = useMemo(() => {
  return slowDouble(number);
}, [number]);

  const theme = {
    backgroundColor: dark ? "#333" : "#FFFFFF",
    color: dark ? "#FFFFFF" : "#000000",
    padding: "1rem",
  };

  return (
    <div style={theme}>

      <input
        type="number"
        value={number}
        onChange={(e) => setNumber(Number(e.target.value))}
      />

      <button onClick={() => setDark(!dark)}>
        Toggle Theme
      </button>

      <h2>Doubled: {doubled}</h2>

    </div>
  );
};

export default SlowEx;
```

Note:
-----
- Changing only the theme still re-runs slowDouble() because the component re-renders.
- useMemo prevents unnecessary recalculation by returning the cached result until the dependency changes.
- Objects (like theme) are also recreated every render. Later we'll optimize them using useMemo.

React Fragments
=========================================================================================

Normally everything inside App should be wrapped inside one parent element.

Example:

```jsx
<div>
  ...
</div>
```

This creates an extra <div> in the DOM.

To avoid the extra element, use:

```jsx
<React.Fragment>
  ...
</React.Fragment>
```

Shorthand:

```jsx
<>
  ...
</>
```

Fragments group multiple elements without creating an extra DOM element.
