Assignment Requirements Explained
================================================================================

The assignment says:

1. Fetch the character list when the component loads.

Meaning:

As soon as the component appears on the screen, call the API.

Flow:

Browser opens
      ↓
Component loads
      ↓
useEffect executes
      ↓
fetch() calls API
      ↓
Receive data
      ↓
Display in table

That's why we use:

useEffect(() => {
    fetchCharacters();
}, []);

--------------------------------------------------------------------------------
Why empty dependency array []?
--------------------------------------------------------------------------------

Because it means:

"Run only once after the first render."

If you remove [], every re-render will call the API again.

================================================================================
2. Display these columns
================================================================================

The assignment asks for:

• image
• name
• status
• species
• gender
• origin

So inside the table we display exactly these six values.

Notice:

character.origin.name

Why?

Because if you inspect the API response you'll see:

{
    "origin": {
        "name": "Earth",
        "url": "..."
    }
}

Origin is an object.

Wrong:

character.origin

Correct:

character.origin.name

================================================================================
3. Show loading while request is running
================================================================================

Suppose the internet takes 5 seconds.

Without loading:

Blank page

User thinks:

"Website is broken."

Instead show:

Loading...

That's why:

const [loading, setLoading] = useState(true);

Initially:

loading = true

After API finishes:

setLoading(false);

================================================================================
4. Show error if request fails
================================================================================

Suppose API URL becomes:

https://rickandmortyapi.com/api/characterrr

The API returns:

404

Instead of crashing, show:

Error: Request Failed!

using:

isError.status

================================================================================
5. Every item needs a key
================================================================================

React renders many rows.

characters.map(...)

Every row must have:

key={character.id}

Why?

React compares the old list with the new list.

Without a key React shows:

Each child in a list should have a unique key.

================================================================================
6. No fetch inside component body
================================================================================

Wrong:

const CharacterTable = () => {

    fetch(URL);

    return (...);

}

Why wrong?

Every render
      ↓
fetch()
      ↓
state update
      ↓
render
      ↓
fetch()
      ↓
Infinite loop

That's why fetch should only be inside:

useEffect()

================================================================================
7. Fetch exactly once
================================================================================

Assignment specifically says:

"Prove it with console.log."

We write:

console.log("Fetching characters...");

inside:

fetchCharacters()

If useEffect runs once, console prints:

Fetching characters...

only once (or twice in React development mode because of StrictMode).

fetchCharacters Function
================================================================================

const fetchCharacters = async () => {

Why async?

Because fetch() returns a Promise.

We use:

await fetch(...)

This function is responsible for:

Calling the API.
Receiving the response.
Converting the response into JSON.
Saving the data in state.
Handling loading and errors.

================================================================================
Loading True
================================================================================

setLoading(true);

Before making the request, show:

Loading...

================================================================================
try Block
================================================================================

try {

All risky code goes here.

--------------------------------------------------------------------------------
console.log()
--------------------------------------------------------------------------------

console.log("Fetching characters...");

Used as proof for the assignment.

--------------------------------------------------------------------------------
API Call
--------------------------------------------------------------------------------

const response = await fetch(URL);

Browser sends an HTTP GET request.

--------------------------------------------------------------------------------
Check Response
--------------------------------------------------------------------------------

if (!response.ok) {
    throw new Error("Request Failed!");
}

Suppose response status is:

404
500
403

Then:

response.ok = false

So we throw an error.

--------------------------------------------------------------------------------
Convert JSON
--------------------------------------------------------------------------------

const data = await response.json();
response.json() is a method that reads the HTTP response body and converts the JSON data into a JavaScript object (or array).

The API sends JSON.

Convert it into a JavaScript object.

Now data contains:

{
    info: {...},
    results: [...]
}

--------------------------------------------------------------------------------
Store Results
--------------------------------------------------------------------------------

setCharacters(data.results);

Notice:

NOT:

data

Because:

results contains the character array.

--------------------------------------------------------------------------------
Remove Error
--------------------------------------------------------------------------------

setIsError({
    status: false,
    msg: ""
});

API succeeded.

No error now, reset the msg.

================================================================================
catch Block
================================================================================

catch(error) {

Runs only if:

• fetch failed
• throw new Error(...) executed

Then:

setIsError({
    status: true,
    msg: error.message
});

}

================================================================================
finally Block
================================================================================

finally {

    setLoading(false);

}

Whether success or failure:

Stop loading.
