Step 8: Cleanup Function (Debouncing)
return () => clearTimeout(timer);

setTimeout() schedules the API call after a 500 ms delay. If the user types again before the delay ends (e.g., changes "Rick" to "Ricky"), React runs the cleanup function first. clearTimeout(timer) cancels the previously scheduled API call, then a new timer starts for the latest input. As a result, only the final search is executed after the user pauses typing. This technique is called debouncing, and it reduces unnecessary API requests while preventing rate-limit issues.

Note: Debouncing (Definition)

Debouncing is a technique that delays the execution of a function until a specified period has passed without any new event occurring. If the event happens again before the delay ends, the previous scheduled execution is cancelled and the timer restarts.
