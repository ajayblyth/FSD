📌 Bootstrap Spacing Utilities (Cheat Sheet)
🔥 Basic Pattern
(property)(side)-(size)
Property:
m  → margin
p  → padding
Side:
t → top
b → bottom
l → left   (older Bootstrap 4)
r → right   (older Bootstrap 4)

ms → margin-start   (Bootstrap 5)
me → margin-end     (Bootstrap 5)

x → left + right
y → top + bottom
(blank) → all sides
📏 Size scale
0 → 0
1 → 0.25rem
2 → 0.5rem
3 → 1rem
4 → 1.5rem
5 → 3rem
auto → auto (only margin)
📌 Margin classes
m-0 → no margin
m-1 → small margin
m-2 → medium-small
m-3 → default
m-4 → large
m-5 → extra large
m-auto → center (auto margin)
📌 Padding classes
p-0 → no padding
p-1 → small padding
p-2 → medium-small
p-3 → default padding
p-4 → large padding
p-5 → extra large padding
📌 Direction examples
Top / Bottom / Left / Right
mt-4 → margin-top
mb-3 → margin-bottom
ms-3 → margin-left (modern)
me-3 → margin-right (modern)

pt-3 → padding-top
pb-3 → padding-bottom
ps-3 → padding-left (Bootstrap 5)
pe-3 → padding-right (Bootstrap 5)
📌 Horizontal / Vertical shortcuts
mx-3 → left + right margin
my-3 → top + bottom margin

px-3 → left + right padding
py-3 → top + bottom padding
📌 Most used in real projects
mt-4   → spacing above element
mb-3   → spacing below element
mx-auto → center horizontally
p-3    → general padding
py-4   → vertical padding
px-3   → horizontal padding
⚠️ Important (Bootstrap 5 change)
ml / mr  → replaced
ms / me  → used instead
