WHAT IS A DATABASE?

A database is an organized collection of data stored electronically
so it can be easily stored, searched, updated, and managed.

Examples:
- Bank customer records
- Instagram users, posts, comments
- Amazon products and orders

==============================================================
WHAT IS MONGODB?
==============================================================

MongoDB is a NoSQL document database that stores data as
JSON-like documents (internally BSON).

Unlike SQL databases that store data in tables, rows, and columns,
MongoDB stores data as collections of documents.

Features:
- Document-based storage
- Flexible schema (schema-less)
- High scalability
- Fast read/write operations
- Open source
- Cross-platform (Windows, Linux, Mac)

Example Document:

{
   "_id": 1,
   "name": "Ajay",
   "age": 30,
   "city": "Bangalore"
}

==============================================================
MONGODB HIERARCHY
==============================================================

Database
   ↓
Collection
   ↓
Document
   ↓
Field

Example:

Database
└── company

    Collection
    └── employees

        Document
        └── {
               "_id": 1,
               "name": "Ajay",
               "age": 30
            }

            Fields
            ├── _id
            ├── name
            └── age

==============================================================
SQL vs MONGODB
==============================================================

+---------------+----------------+---------------------------+
| SQL           | MongoDB        | Meaning                   |
+---------------+----------------+---------------------------+
| Database      | Database       | Top container             |
| Table         | Collection     | Group of records          |
| Row           | Document       | One record                |
| Column        | Field          | One property              |
| Primary Key   | _id            | Unique identifier         |
| JOIN          | $lookup        | Link related data         |
| SELECT *      | find()         | Get all records           |
+---------------+----------------+---------------------------+

==============================================================
WHEN TO USE SQL?
==============================================================

Use SQL when:

✔ Data is highly structured
✔ Many related tables exist
✔ ACID transactions are critical
✔ Schema rarely changes
✔ Data consistency is very important

Examples:
- Banking systems
- Payment gateways
- Accounting software
- Inventory management
- Airline reservation systems

Example:

Customers
    ↓
Accounts
    ↓
Transactions
    ↓
Loans

Many relationships between tables.

==============================================================
WHEN TO USE MONGODB?
==============================================================

Use MongoDB when:

✔ Data is semi-structured
✔ Fields vary between records
✔ Schema changes frequently
✔ High-volume reads/writes
✔ Real-time applications
✔ Rapid development required

Examples:
- Social media apps
- Chat applications
- Blogging platforms
- Product catalogs
- IoT applications

Instagram Example:

Post 1:
{
   "caption": "Hello",
   "likes": 100,
   "comments": [...]
}

Post 2:
{
   "caption": "Trip Photos"
}

Both documents can have different fields.

==============================================================
SQL vs MONGODB (INTERVIEW ANSWER)
==============================================================

SQL:
- Structured data
- Fixed schema
- Strong relationships
- ACID transactions
- Best for banking, finance, ERP

MongoDB:
- Semi-structured data
- Flexible schema
- High scalability
- Faster development
- Best for social media, chat apps,
  real-time applications
