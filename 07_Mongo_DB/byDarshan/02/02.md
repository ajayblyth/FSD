13. NESTED DOCUMENTS
======================================================================

WHAT IS IT?
- A field whose value is another document (object)
- Used to keep related data together

Example

{
  name: "Vihaan",
  age: 29,
  address: {
    city: "Bangalore",
    state: "Karnataka",
    zipCode: "560001"
  }
}

----------------------------------------------------------------------

INSERT

db.students.insertOne({
  name: "Vihaan",
  age: 29,
  address: {
    city: "Bangalore",
    state: "Karnataka",
    zipCode: "560001"
  }
})

----------------------------------------------------------------------

QUERY USING DOT NOTATION

db.students.find({
  "address.city": "Bangalore"
})

db.students.find({
  "address.state": "Karnataka",
  "address.zipCode": "560001"
})

IMPORTANT
- Dot path must be inside quotes
- "address.city"  ✅
- address.city    ❌ Syntax Error

14. ARRAYS
======================================================================

WHAT IS IT?
- A field containing multiple values

Example

{
  name: "Ishaan",
  skills: ["JavaScript","React","MongoDB"]
}

----------------------------------------------------------------------

INSERT

db.students.insertOne({
  name: "Ishaan",
  skills: ["JavaScript","React","MongoDB"]
})

----------------------------------------------------------------------

QUERY ARRAY

db.students.find({
  subjects: "Math"
})

MongoDB checks every element.
Matches if ANY element equals "Math".

----------------------------------------------------------------------

$in OPERATOR

db.students.find({
  subjects: {
    $in: ["Math","Science"]
  }
})

Matches if array contains:
- Math OR
- Science

16. SCHEMA VALIDATION
======================================================================

WHY VALIDATION?

Without validation:

❌ age stored as string
❌ missing required fields
❌ negative values
❌ inconsistent documents

Validation ensures:

✅ correct types
✅ required fields
✅ valid ranges
✅ clean data

17. VALIDATOR STRUCTURE
======================================================================

Syntax

db.createCollection("employees_validated", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["name","age"],
      properties: {
        name: {
          bsonType: "string"
        },
        age: {
          bsonType: "int",
          minimum: 18
        }
      }
    }
  }
})

----------------------------------------------------------------------

KEYWORDS

+------------------+--------------------------------------+
| Keyword          | Purpose                              |
+------------------+--------------------------------------+
| validator        | Holds validation rules              |
| $jsonSchema      | Validation language                 |
| bsonType         | Required BSON type                  |
| required         | Mandatory fields                    |
| properties       | Field-specific rules                |
| minimum          | Minimum numeric value               |
| maximum          | Maximum numeric value               |
+------------------+--------------------------------------+

----------------------------------------------------------------------

COMMON BSON TYPES

string
int
double
bool
array
object
date
objectId

18. VALIDATION IN ACTION
======================================================================

REJECTED

Missing required field

db.employees_validated.insertOne({
  name: "Tarun"
})

Reason:
- age field missing

----------------------------------------------------------------------

REJECTED

Wrong datatype

db.employees_validated.insertOne({
  name: "Tarun",
  age: "25"
})

Reason:
- age must be int

----------------------------------------------------------------------

REJECTED

Below minimum value

db.employees_validated.insertOne({
  name: "Tarun",
  age: 15
})

Reason:
- minimum age is 18

----------------------------------------------------------------------

ACCEPTED

db.employees_validated.insertOne({
  name: "Tarun",
  age: 25
})

19. NULL vs MISSING FIELD
======================================================================

NULL FIELD
- Field exists
- Value is null

Example

{
  name: "Meera",
  age: null
}

----------------------------------------------------------------------

MISSING FIELD
- Field does not exist

Example

{
  name: "Sahil"
}

----------------------------------------------------------------------

DIFFERENCE

+----------------+----------------+----------------+
| Check          | NULL           | MISSING        |
+----------------+----------------+----------------+
| Field Exists   | Yes            | No             |
| Has Value      | No             | No             |
+----------------+----------------+----------------+

----------------------------------------------------------------------

MATCHES BOTH NULL AND MISSING

db.students.find({
  age: null
})

----------------------------------------------------------------------

ONLY NULL

db.students.find({
  age: {
    $eq: null,
    $exists: true
  }
})

----------------------------------------------------------------------

ONLY MISSING

db.students.find({
  age: {
    $exists: false
  }
})

----------------------------------------------------------------------

ONLY FIELD EXISTS

db.students.find({
  age: {
    $exists: true
  }
})

IMPORTANT INTERVIEW POINT

age:null
→ matches NULL + MISSING

$exists:true
→ field present (even if value is null)

  }

21. ARRAY OF OBJECTS
======================================================================

Example

marks: [
  {subject:"Math",score:90},
  {subject:"Science",score:85}
]

----------------------------------------------------------------------

QUERY

db.students.find({
  "marks.subject": "Math"
})

----------------------------------------------------------------------

QUERY SCORE > 90

db.students.find({
  "marks.score": {
    $gt: 90
  }
})

----------------------------------------------------------------------

BEST WAY : $elemMatch

db.students.find({
  marks: {
    $elemMatch: {
      subject: "Math",
      score: { $gt: 80 }
    }
  }
})

WHY?

Without $elemMatch:
- Conditions may match different array elements

With $elemMatch:
- Same array element must satisfy all conditions

22. ADDITIONAL ARRAY OPERATORS
======================================================================

$push
Add element to array

Example

db.students.updateOne(
  {name:"Pooja"},
  {$push:{subjects:"MongoDB"}}
)

----------------------------------------------------------------------

$pull
Remove element from array

Example

db.students.updateOne(
  {name:"Pooja"},
  {$pull:{subjects:"English"}}
)

----------------------------------------------------------------------

$addToSet
Add only if value does not already exist

Example

db.students.updateOne(
  {name:"Pooja"},
  {$addToSet:{subjects:"MongoDB"}}
)

----------------------------------------------------------------------

INTERVIEW POINT

$push
→ allows duplicates

$addToSet
→ prevents duplicates

Yes. You can add validation after the collection already exists using the collMod command.

Example
db.runCommand({
  collMod: "employees",
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["name", "age"],
      properties: {
        name: {
          bsonType: "string"
        },
        age: {
          bsonType: "int",
          minimum: 18
        }
      }
    }
  }
})
What happens?
Existing Collection
        ↓
Apply collMod
        ↓
Validation Added
        ↓
Future Inserts/Updates Checked

Nothing happens to existing documents.
