22. REFINING find() RESULTS
======================================================================

These methods refine the documents returned by find().

----------------------------------------------------------------------

sort()

Purpose:
Order documents.

db.students.find().sort({
  marks:-1
})

1  = Ascending
-1 = Descending

----------------------------------------------------------------------

Examples

Highest marks first

db.students.find().sort({
  marks:-1
})

Lowest marks first

db.students.find().sort({
  marks:1
})

Multiple fields

db.students.find().sort({
  city:1,
  marks:-1
})

----------------------------------------------------------------------

limit()

Purpose:
Return only first N documents.

db.students.find().limit(3)

Example

db.students.find()
           .sort({marks:-1})
           .limit(3)

----------------------------------------------------------------------

skip()

Purpose:
Ignore first N documents.

db.students.find().skip(5)

----------------------------------------------------------------------

PROJECTION

Purpose:
Choose which fields to display.

db.students.find(
 {},
 {
   name:1,
   _id:0
 }
)

Rules

1 = Include
0 = Exclude

----------------------------------------------------------------------

PAGINATION

Formula

skip = (page - 1) * pageSize

Example

Page 1

db.students.find()
           .skip(0)
           .limit(5)

Page 2

db.students.find()
           .skip(5)
           .limit(5)

Page 3

db.students.find()
           .skip(10)
           .limit(5)

----------------------------------------------------------------------

INTERVIEW POINT

skip() + limit()
=
Pagination

23. AGGREGATION PIPELINE
======================================================================

WHAT IS AGGREGATION?

- Process documents in stages
- Similar to SQL GROUP BY
- Computes results, not just fetches data

WHY USE IT?

✔ Reports
✔ Analytics
✔ Grouping
✔ Totals
✔ Averages
✔ Data Transformation

Syntax

db.collection.aggregate([
  { stage1 },
  { stage2 }
])

Pipeline Flow

Documents
   ↓
$match
   ↓
$group
   ↓
$project
   ↓
Result

======================================================================

24. $match
======================================================================

Purpose:
Filter documents.

Equivalent to find().

Example

db.students.aggregate([
  {
    $match:{
      city:"Delhi"
    }
  }
])

----------------------------------------------------------------------

INTERVIEW POINT

find()
→ Normal query

$match
→ Aggregation filter

======================================================================

25. $group
======================================================================

Purpose:
Group documents.

Equivalent to SQL GROUP BY.

Group by city

db.students.aggregate([
  {
    $group:{
      _id:"$city"
    }
  }
])

----------------------------------------------------------------------

Count students per city

db.students.aggregate([
  {
    $group:{
      _id:"$city",
      totalStudents:{
        $sum:1
      }
    }
  }
])

======================================================================

======================================================================

Used mainly inside $group.

----------------------------------------------------------------------

$sum

{
  $sum:1

----------------------------------------------------------------------

$avg

----------------------------------------------------------------------

$min

{
  $min:"$marks"
}

----------------------------------------------------------------------

$max

{
  $max:"$marks"
}

----------------------------------------------------------------------

$first

{
  $first:"$name"

Returns first value in group.

----------------------------------------------------------------------

$last

{
  $last:"$name"

$push

27. GROUP EXAMPLES
======================================================================

Average age by city

db.students.aggregate([
  {
    $group:{
      _id:"$city",
      avgAge:{
        $avg:"$age"
      }
    }
  }
])

----------------------------------------------------------------------

Highest marks by city

db.students.aggregate([
  {
    $group:{
      _id:"$city",
      highestMarks:{
        $max:"$marks"
      }
    }
  }
])

----------------------------------------------------------------------

Total students by course

db.students.aggregate([
  {
    $group:{
      _id:"$course",
      totalStudents:{
        $sum:1
      }
    }
  }
])

----------------------------------------------------------------------

First and Last Student

db.students.aggregate([
  {
    $group:{
      _id:"$city",
      firstStudent:{
        $first:"$name"
      },
      lastStudent:{
        $last:"$name"
      }
    }
  }
])

----------------------------------------------------------------------

Create Array of Student Names

db.students.aggregate([
  {
    $group:{
      _id:"$city",
      students:{
        $push:"$name"
      }
    }
  }
])

======================================================================

28. $project
======================================================================

Purpose:
Reshape output documents.

Can

✔ Include fields
✔ Exclude fields
✔ Rename fields
✔ Create calculated fields

----------------------------------------------------------------------

Rename field

db.students.aggregate([
  {
    $project:{
      studentName:"$name",
      _id:0
    }
  }
])

Output

{
  studentName:"Pooja"
}

----------------------------------------------------------------------

IMPORTANT

$project defines final output structure.

======================================================================

29. $addFields
======================================================================

Purpose:
Add fields while keeping existing fields.

Example

db.students.aggregate([
  {
    $addFields:{
      status:"Active"
    }
  }
])

----------------------------------------------------------------------

Difference

$project
→ Reshape document

$addFields
→ Add fields
