Good — this is EJS partials (includes) 👍
Used to avoid repeating common code like <!DOCTYPE html>, header, navbar, etc.

🔹 Goal

👉 Reuse common top part (HTML start)

🔹 Step 1: Create partial file

Create folder:

views/includes/

Create file:

views/includes/header.ejs
🔹 header.ejs
<!DOCTYPE html>
<html>
<head>
    <title>Chat App</title>
</head>
<body>
🔹 Step 2: Create footer (important)
views/includes/footer.ejs
</body>
</html>
🔹 Step 3: Use include in your pages
index.ejs / new.ejs

At top:

<%- include("includes/header") %>

At bottom:

<%- include("includes/footer") %>
🔹 Why <%- not <%= ?
<%- → renders HTML properly ✔
<%= → escapes HTML ❌

👉 Always use <%- include(...) %>

🔹 Folder structure
views/
   index.ejs
   new.ejs
   includes/
       header.ejs
       footer.ejs
🔹 Result

Now:

No repeated DOCTYPE
Clean files
Easy to maintain
🔹 One-line

👉 EJS include lets you reuse common UI parts like header/footer.
