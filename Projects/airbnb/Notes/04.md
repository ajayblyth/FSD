Creating a Router
Let's refactor the previous example by creating a Router for the /about
route.

1. Create a separate router file (e.g., aboutRoutes.js:

const express = require('express');
const router = express.Router ();

// Define the routes for this router
router.get('/', (req, res) => {
res.send('About Page');
1;

module.exports = router;
In your main app. js, you'll now import the router and tell your main app to
use it:

const express = require('express');
const aboutRoutes = require('./aboutRoutes'); // Import the router
const app = express();
const port = 3000;

// Use the router for the /about path
app.use('/about', aboutRoutes);

app.get('/', (req, res) => {
res. send ('Home Page') ;
