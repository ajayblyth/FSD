=============================================================================
COOKIES (WEB COOKIES)
=============================================================================

Cookies are small pieces of data created by a web server and stored
inside the user's browser.

The browser automatically sends cookies back to the SAME website
in future requests.

=============================================================================
REAL-LIFE EXAMPLE
=============================================================================

"This website uses cookies"

[ ACCEPT ]

-----------------------------------------------------------------------------
Meaning:
-----------------------------------------------------------------------------
Website stores small data in browser for future use.

=============================================================================
WHY COOKIES ARE USED
=============================================================================

Use                    | Meaning
-----------------------------------------------------------------------------
Login Session          | Remember logged-in user
User Preference        | Save theme, language, location
Cart Data              | Store products in shopping cart
Tracking               | Analyze user behavior/pages visited
Security               | Store session ID or CSRF token

=============================================================================
HOW COOKIES WORK
=============================================================================

1. Server sends cookie
2. Browser stores cookie
3. Browser sends cookie back automatically later

=============================================================================
EXPRESS - SEND COOKIE
=============================================================================

app.get("/setcookies", (req, res) => {

  res.cookie("greet", "namaste");

  res.cookie("origin", "India");

  res.send("We sent you a cookie!");
});

-----------------------------------------------------------------------------
WHAT HAPPENS:
-----------------------------------------------------------------------------
• Browser stores:
  greet  = namaste
  origin = India

=============================================================================
COOKIE-PARSER PACKAGE
=============================================================================

Install:
-----------------------------------------------------------------------------
npm install cookie-parser

=============================================================================
IMPORT + USE
=============================================================================

const cookieParser = require("cookie-parser");

app.use(cookieParser());

=============================================================================
WHY cookie-parser IS USED
=============================================================================

• Reads cookies from browser requests
• Makes cookies available in:

req.cookies

=============================================================================
SIGNED COOKIES
=============================================================================

Signed cookies are protected against tampering/modification.

-----------------------------------------------------------------------------
PURPOSE:
-----------------------------------------------------------------------------
• Prevent users from changing cookie values manually

=============================================================================
SETUP SIGNED COOKIE
=============================================================================

app.use(cookieParser("secretcode"));

=============================================================================
SEND SIGNED COOKIE
=============================================================================

app.get("/getsignedcookie", (req, res) => {

  res.cookie("color", "red", { signed: true });

  res.send("done!");
});

=============================================================================
VERIFY SIGNED COOKIE
=============================================================================

app.get("/verify", (req, res) => {

  res.send(req.signedCookies);
});

=============================================================================
IMPORTANT UNDERSTANDING
=============================================================================

req.cookies
-----------------------------------------------------------------------------
• normal cookies

req.signedCookies
-----------------------------------------------------------------------------
• verified signed cookies

=============================================================================
SIMPLE FLOW
=============================================================================

Server
  ↓ sends cookie
Browser stores cookie
  ↓
Browser sends cookie automatically later
  ↓
Server reads cookie using req.cookies

=============================================================================
